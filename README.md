# FX Simulator V2.0

一个完全离线、使用虚拟随机行情的 Windows 外汇交易模拟器。仅用于娱乐与学习，不连接券商，不使用真实资金。

## V2.0 更新

- **重新设计行情区**：将货币对选择器放到 K 线面板顶部，打开软件即可看到并切换 USD/JPY、EUR/JPY、GBP/JPY。
- **重做 K 线图**：使用 OHLC 蜡烛图，显示开盘价、最高价、最低价、收盘价；绿色表示上涨蜡烛，红色表示下跌蜡烛，并显示价格网格与最新价格线。
- **减少界面卡顿**：行情刷新时不再每次清空并重建全部持仓行；历史记录只在记录列表变化时重建；K 线采用双缓冲绘制并限制显示数量。
- 保留买入/做多绿色按钮、卖出/做空红色按钮、账户指标、手数/杠杆设置、平仓、保证金强平和本地自动保存。
- 沿用 V1.x 的账户数据路径，升级时尽量保留现有账户。

## 功能说明

- 虚拟随机行情：USD/JPY、EUR/JPY、GBP/JPY。
- 余额、净值、浮动盈亏、已用保证金和保证金率。
- 做多、做空、选择持仓平仓、全部平仓。
- 交易手数与杠杆设置；模拟保证金强平。
- 自动保存账户、设置、持仓和最近交易记录。
- 本地数据文件：`%LOCALAPPDATA%\FXSimulator\account.json`。

## 运行方式

安装 .NET 8 SDK 后，在项目目录执行：

```powershell
dotnet run --project FXSimulator/FXSimulator.csproj
```

## GitHub Actions 构建 Windows x64

1. 将本 ZIP 解压后的所有内容上传到 GitHub 仓库根目录（包括 `.github` 文件夹）。
2. 在仓库的 **Actions** 页面启用 Actions。
3. 运行 `Build Windows App` 工作流。
4. 在运行记录的 Artifacts 中下载 `FXSimulator-V2.0-win-x64`。

## 重要说明

行情是随机生成的，不代表真实汇率；交易、杠杆、保证金和强平仅为模拟机制，不提供投资建议。
